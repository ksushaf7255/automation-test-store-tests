# Test Plan — Automation Test Store

## 1. Цель тестирования

Цель тестирования — проверить основные функции интернет-магазина Automation Test Store и убедиться, что регистрация, авторизация, поиск товаров, корзина, оформление заказа и личный кабинет работают корректно.

## 2. Тестируемое приложение

- **Название:** Automation Test Store
- **URL:** https://automationteststore.com/
- **Тип:** учебный интернет-магазин

Приложение доступно онлайн, поэтому локальная установка не требуется. Перед началом тестирования рекомендуется очистить cookies и кеш браузера или использовать режим инкогнито.

## 3. Области тестирования

| Область | Что проверяется | Приоритет |
|---------|-----------------|-----------|
| Регистрация и авторизация | Регистрация, вход, выход, восстановление пароля | High |
| Каталог | Поиск, категории, карточки товаров | High |
| Корзина | Добавление, удаление, изменение количества | High |
| Оформление заказа | Адрес, доставка, оплата, подтверждение | Critical |
| Личный кабинет | Профиль, история заказов, адресная книга | Medium |
| Сквозной сценарий | Покупка товара от поиска до подтверждения | Critical |

Эти области соответствуют функциональности, указанной в задании.

## 4. Виды тестирования

В ходе работы выполняется **ручное функциональное тестирование**.

Проверяются:

- позитивные сценарии;
- негативные сценарии;
- обязательные поля;
- некорректные данные;
- переходы между страницами;
- корректность отображения результатов действий пользователя.

## 5. Тестовая среда

- **ОС:** Windows
- **Браузер:** Google Chrome
- **Сайт:** Automation Test Store
- **Тестирование:** ручное

## 6. Тестовые данные

Для регистрации использовались тестовые данные пользователя.

Для проверки оформления заказа использовались тестовые адресные данные и доступные способы доставки и оплаты.

**Реальные платежи не выполняются**, так как сайт предназначен для учебного тестирования.

## 7. Тест-кейсы

Для проверки подготовлено **25 тест-кейсов**, включающих позитивные и негативные сценарии.

Тест-кейсы охватывают:

- регистрацию;
- авторизацию;
- восстановление пароля;
- поиск товаров;
- фильтрацию по категориям;
- работу с корзиной;
- оформление заказа;
- личный кабинет;
- историю заказов;
- Invoice;
- сквозной сценарий покупки.

## 8. Результаты тестирования

По результатам ручного тестирования результаты каждого тест-кейса занесены в файл `test-cases.md`.

Большинство основных сценариев были проверены вручную. Для каждого выполненного теста указаны статус, фактический результат и приложен скриншот.

Для **TC-017** тест не выполнялся, поскольку действующий тестовый код купона не был предоставлен.

При проверке **TC-023** обнаружено, что страница Invoice заказа №71397 отображает сообщение: **«The order you have requested could not be found!»**.

Данный дефект оформлен отдельно в `bug-reports.md` как **BUG-001**.

## 9. Дефекты

В ходе ручного тестирования обнаружен подтверждённый дефект:

**BUG-001 — Невозможно открыть Invoice заказа №71397.**

При переходе на страницу Invoice отображается сообщение о том, что запрошенный заказ не найден.

## 10. Итог

В результате работы был подготовлен комплект документации для ручного тестирования Automation Test Store:

- тест-план;
- 25 тест-кейсов;
- результаты выполнения тестов;
- скриншоты;
- баг-репорт обнаруженного дефекта.

**Ручная часть тестирования завершена.**
