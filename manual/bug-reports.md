# Bug Reports — Automation Test Store

## BUG-001 — Невозможно открыть Invoice заказа №71397

**Окружение:**
- ОС: Windows
- Браузер: Microsoft Edge
- URL: https://automationteststore.com/index.php?rt=account/invoice&order_id=71397

**Предусловия:**
Открыт сайт Automation Test Store. Пользователь имеет доступ к странице Invoice.

**Шаги воспроизведения:**
1. Открыть сайт Automation Test Store.
2. Перейти по адресу страницы Invoice заказа №71397.
3. Дождаться загрузки страницы.
4. Проверить отображаемую информацию.

**Ожидаемый результат:**
Открывается страница с подробной информацией об Invoice заказа №71397.

**Фактический результат:**
Вместо информации о заказе отображается сообщение: **«The order you have requested could not be found!»**
Страница с деталями заказа не открывается.

**Серьёзность:** Major
**Приоритет:** Medium

**Вложения:**
Скриншот страницы с сообщением «The order you have requested could not be found!».
