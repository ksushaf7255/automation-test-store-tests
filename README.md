# Automation Test Store — Test Automation Project

Учебный проект по автоматизации тестирования интернет-магазина [Automation Test Store](https://automationteststore.com/) с использованием TestCafe и TypeScript.

## Что внутри

- **manual/** — ручное тестирование (тест-план, тест-кейсы, баг-репорты)
- **tests/specs/** — автоматизированные тесты
- **tests/pages/** — Page Objects
- **tests/helpers/** — вспомогательные функции

## Требования

- Node.js 20+
- npm
